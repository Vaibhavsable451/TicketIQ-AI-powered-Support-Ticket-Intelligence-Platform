# Account and security
Password reset emails arrive within 5 minutes; check spam and verify the address. After 5 failed logins an account locks for 30 minutes, or can be unlocked via the reset link.
Two factor authentication can be enabled in Settings > Security using any authenticator app.
Email changes require confirmation from both the old and new address. Account deletion removes personal data within 30 days in line with GDPR; request it from Settings > Privacy.
